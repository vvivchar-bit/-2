## Опис роботи

У межах практичного заняття було виконано такі завдання:

1. Створено власний компонент **TBtnNClick** на основі `TButton`, який підраховує кількість натискань і відображає її на кнопці.
2. Створено власний компонент **TSG** на основі `TStringGrid`, який:
   - при натисканні **F11** заповнює комірки випадковими числами від 0 до 20;
   - при натисканні **Esc** очищує комірки;
   - при клацанні мишкою збільшує розмір шрифту в окремій комірці.
3. Виконано інсталяцію компонента **TBtnNClick** у палітру компонентів C++ Builder через пакет **MyCompn**.

## Основні результати

### Завдання 1
Компонент **TBtnNClick** успішно створено та перевірено в роботі.  
Після кожного натискання кнопки її текст змінюється і відображає кількість клацань.

### Завдання 2
Компонент **TSG** успішно створено та перевірено.  
Таблиця:
